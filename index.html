Creator and productivity workloads

Each application stresses different parts, so CoreForge describes what limits each one instead of giving a single score.

Adobe Premiere Pro

Timeline playback and export lean on CPU cores, GPU encoders and RAM.

Adobe After Effects

Memory-hungry; RAM and single-core speed matter most.

DaVinci Resolve

GPU compute and VRAM drive effects and color work.

Adobe Photoshop

Responsiveness depends on single-core speed and RAM.

Blender

CPU cores for CPU rendering; GPU and VRAM for GPU rendering.

Autodesk AutoCAD

Mostly single-core; a modest GPU is usually enough.

Visual Studio Code

Light on hardware; fast storage and RAM help with large projects.

Android Studio

RAM and CPU threads matter, especially with the emulator.

Unreal Engine

VRAM, RAM and CPU cores affect editor and shader compile times.

OBS Studio

Hardware encoders reduce the load when gaming and streaming.

Multitasking and office

RAM capacity and an SSD matter more than a fast GPU.
