CPU sockets explained

Why a processor and board must match.

The socket is the physical and electrical interface between a processor and the motherboard. AM4, AM5 and LGA1700 are different designs and are not interchangeable.

Within a socket, support still varies. A board may need a BIOS update before it recognizes a newer processor, so check the manufacturer's CPU support list.

The socket also usually determines memory type. AM5 uses DDR5. AM4 uses DDR4. LGA1700 boards exist for DDR4 or DDR5, so check the board.
